# Morse-Code-Signal
This project 

The users can input words, numbers or sentences into a GUI. The characters are then converted into morse code, and then signaled with the LED light. 

|**Materials**|
|---|
|Arduino R3|
|Red LED (Ω)|
|330Ω Resistor|
|2 Male to Male Wires|
